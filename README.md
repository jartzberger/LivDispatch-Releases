# LivDispatch by LivOrigin

**Turn any headline into a finished, documentary-style news explainer video.** AI researches the story, writes the script, narrates it, creates every shot and edits it together with music.

## Download

🎁 **[Download LivDispatch Free](https://github.com/jartzberger/LivDispatch-Releases/releases/tag/free-v1.0.0-build8)**: the free community edition (`LivDispatch-Free-Setup.exe` for Windows, `LivDispatch-Free-Mac.dmg` for Mac).

**LivDispatch (full version):**

👉 **[Get the latest LivDispatch](https://github.com/jartzberger/LivDispatch-Releases/releases/latest)**

- **Windows:** download `LivDispatch-Setup.exe` and double-click it. If Windows says "Windows protected your PC", click **More info → Run anyway**.
- **Mac (Apple Silicon, M1 or newer):** download `LivDispatch-Mac.dmg`, open it and drag LivDispatch into Applications. The first time, macOS blocks it: open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.

LivDispatch updates itself: open it and press **Update now** when a new version is ready.

## Getting started

1. Open LivDispatch → **Settings**.
2. Paste your keys and press **Save & test keys**:
   - Claude: console.anthropic.com → API Keys
   - Kie AI: kie.ai/api-key
   - ElevenLabs: elevenlabs.io → Developers → API Keys
3. **New dispatch** → type a story (or leave it blank for today's top story) → pick 1 chapter → go.

No keys yet? The app runs in free demo mode so you can try every screen.
